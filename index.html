Welcome to My GitHub Page

A simple example showing how to create links in HTML.

Basic idea of a link

A link in HTML uses the <a> tag and the href attribute, like this: 

<a href="https://example.com">Visit Example</a>

What the user sees is the text between the opening and closing tags, for example Visit Example.

Examples you can copy

1. Link to another website

Code:

<a href="https://github.com">Go to GitHub</a>

Result:

Go to GitHub

2. Open link in a new tab

Code:

<a href="https://pages.github.com" target="_blank" rel="noopener noreferrer">
  Learn about GitHub Pages
</a>

Result:

Learn about GitHub Pages

3. Link to another page in your repo

Imagine you have another file called about.html in the same folder.

Code:

<a href="about.html">About this site</a>

Result (this will work once you actually create about.html):

About this site

4. Link to a section on the same page

First give a section an id:

<h2 id="contact">Contact</h2>

Then link to it with # plus that id:

<a href="#contact">Jump to contact section</a>

Result:

Jump to contact section

Contact

Example email link: 

<a href="mailto:you@example.com">Email me</a>

Result:

Email me

Checklist for your own links

  • Use <a> with an href attribute.
  • Put the clickable text between <a> and </a>.
  • Use full URLs (starting with https://) for external sites.
  • Use relative paths (like about.html or folder/page.html) for your own pages.
